Your own TMDB key for SerKal

SerKal uses The Movie Database (TMDB) to find series, seasons, episodes, descriptions and images. Every SerKal user uses their own free TMDB Developer access and their own API key.

Important: SerKal does not ship with a shared API key or with the developer's personal key. Your TMDB key belongs only to you.

1. Create a free TMDB account

Open The Movie Database and create a free account, or sign in with an existing account.

TMDB notes that API-key registration is best completed on a desktop computer in a browser.

2. Request a Developer key

  1. Open your Settings on TMDB.
  2. Select API in the left-hand menu.
  3. Request an API key and choose Developer.
  4. Accept the TMDB terms of use and complete the form with your own details.

For private use of SerKal, the application details can for example be entered like this:

Type of Use: Personal
Application Name: SerKal
Application URL: https://serkal.de
Application Summary: Personal use of SerKal to retrieve TV series, season, episode and image information from TMDB.

If TMDB asks for additional personal contact details, enter your own correct information there.

3. Enter the API key in SerKal

After successful registration, TMDB displays your personal API key. Copy the API Key (v3 auth) and enter it in SerKal's settings in the TMDB API Key field.

SerKal stores this key locally on your own computer, so you normally only have to enter it once.

4. Keep your key private

Treat the API key like a personal credential. Do not publish it, show it in screenshots or share it with other users.

Each SerKal user requests their own key, so nobody needs to share another person's key.

What works without a TMDB key?

SerKal can still be started without a TMDB key. Existing archive data and local functions remain available.

Without a valid key, however, TMDB search, TMDB images and TMDB-based maintenance do not work.
