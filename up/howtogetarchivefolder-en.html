Prepare archive folder

This guide explains how to prepare the Google Drive archive folder for SerKal.

Prepare archive folder

SerKal stores archive data in a Google Drive folder.

1. Open Google Drive

https://drive.google.com

2. Create a new folder

Recommended name: SerKal_Archivdaten.

3. Open the folder

Open the folder and copy the long ID from the address bar.

4. Enter ID in SerKal

This ID is used in the SerKal configuration.

Note: Use the folder ID, not the folder name.
