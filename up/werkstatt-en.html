SerKal Workshop

Unfinished things are allowed here. SerKal began in Google Sheets, became a standalone Windows application and then made the leap to Android. This development diary follows that journey through drafts, working builds, successes and changing ideas.

8 March 2025

Before SerKal became a program of its own

SerKal originally lived entirely in Google Sheets and Google Apps Script. Episode dates were stored in a spreadsheet, while a sidebar collected title, year, season, start date and episode count.

Seasons and episodes already belonged together, broadcast dates were listed clearly, and the calendar stood at the centre.

This was the starting point from which SerKal Desktop – and later the Android idea – emerged.
4 August 2026

A rather big idea

What if SerKal could simply be installed? No Apps Script editor, no modules to copy and no personal web app to deploy. Download, install and start.

That question became the plan for SerKal Desktop. The existing interface and years of program logic formed the foundation.

7 August 2026

Three days later: it is alive

SerKal Desktop 0.0.1 – Build 0001 ran as a standalone Windows application.

No series search, archive or calendar yet. But it ran.

Electron and Node.js formed the new foundation.

✓ Windows window✓ Electron✓ Node.js○ interface○ search○ archive○ calendar
11 August 2026

Version 0.0.2 – the interface moves in

The familiar SerKal interface moved into the Windows application. Full-screen operation, Light and Dark Mode, and switching between German and English already worked.

This was the first version that not only ran, but already looked recognisably like SerKal.
August 2026

Versions 0.0.3 to 0.0.5 – real data returns

The interface study became a real desktop edition. Version 0.0.5 loaded the existing archive, displayed season information, TMDB descriptions and artwork, and allowed series to be searched, added and edited.

Google Calendar – now directly

After one OAuth approval, SerKal could write episode dates straight into the selected Google Calendar. ICS remained available for other calendars.

The first complete practical test used Reacher, season 4. Every episode date appeared automatically with the correct calendar colour.

✓ search✓ archive✓ TMDB details✓ direct calendar entries✓ save and edit
All eight steps of the original desktop workflow had now been implemented.
September 2026

The workshop becomes SerKal Desktop 1.0

After many intermediate builds, release candidates and tests on several computers, SerKal Desktop 1.0 was released. Its technical version was 1.0.5, displayed as Build 1.0005.

The empty Electron window had become an installable Windows program with guided setup, TMDB search, an archive and calendar support.

✓ Windows installer✓ German and English✓ TMDB search✓ series archive✓ Google Calendar✓ ICS alternative
In roughly a year and a half, a Google Sheet had become a standalone desktop application.
September 2026

The next beginning: SerKal on Android

A first APK launched on a Google Pixel 8 and a Samsung tablet. The prototype already switched between German and English, but the desktop interface had to be reshaped for smaller screens, safe edges and landscape use.

✓ first APK✓ Pixel 8✓ Samsung tablet✓ German/English○ scalable interface○ desktop feature set
The first prototype ran – the Android story had begun.
26 October 2026

SerKal 1.2: Android becomes public

SerKal 1.2 was released for Windows and Android. Both editions could share the same archive; changes were saved safely on the device and then synchronised with Google in the background.

Search became smarter, maintenance gained a result list, announced seasons could remain without invented episode dates, streaming providers could be shown by country, and users could choose the authoritative archive when copies disagreed.

Android grows up

The Android interface used available space more effectively. Its compact footer included language, Light/Dark, calendar, help and a genuine Exit action.

✓ Desktop 1.2✓ public Android APK✓ shared archive✓ Windows and Android✓ Light and Dark Mode✓ verified signatures
The cautious September prototype became part of one shared public SerKal release.
