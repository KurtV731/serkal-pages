Frequently asked questions about SerKal

This page explains not only how things work, but especially why SerKal does certain things the way it does.

Why does SerKal use TMDB? Are there no alternatives?

SerKal needs a reliable source for series, seasons, episodes, release dates and images. It uses the TMDB API for this purpose. Other sources would be possible in principle, but would require another data integration with its own rules and maintenance. SerKal therefore focuses on TMDB.

Why do I need my own TMDB API key?

Access to the TMDB API uses a personal API key. SerKal deliberately does not ship one shared key for all users. Each user uses their own free TMDB access.

Does the TMDB API key cost anything?

For normal SerKal use, a free TMDB account with its own API key is used. Setup instructions are available in the TMDB help page.

Why doesn't SerKal simply include an API key?

A central bundled key would be shared by every installation and would have to be distributed inside the software. SerKal deliberately keeps this separate: the personal key stays with the individual user.

What data does TMDB receive from me?

SerKal requests the information needed for series management through the TMDB API. SerKal's own archive remains separate and is not uploaded to TMDB as your personal series archive.

Do I absolutely need a Google account?

No. A Google account enables direct calendar integration and is the most convenient route. Without Google, SerKal can alternatively provide calendar data as ICS.

Why does Google ask for permissions on the first connection?

To let SerKal manage appointments in your Google Calendar, Google must explicitly grant that access once. The individual steps are explained in the Google Calendar help page.

What is the difference between Google Calendar and ICS?

With direct Google integration, SerKal can manage calendar entries directly. An ICS file, on the other hand, is imported into a calendar and is then a snapshot of that import.

Why are later changes not automatically applied after importing an ICS file?

An ICS import is not permanent synchronization. After import there is no ongoing connection between the file and the calendar entries that were created.

Where is my series data stored – locally or online?

The SerKal archive is designed as local data. Online services are used where SerKal needs current information or a requested calendar connection.

Does SerKal need a permanent internet connection?

Not for local archive data. An internet connection is required for current TMDB queries and direct use of online services.

Why might Windows display a message during installation?

Windows can show additional security prompts for new or not yet widely used software. SerKal is working to make installation of the finished desktop versions as straightforward as possible.

Can I use SerKal without TMDB or Google?

Local functions and archive data are separated from these services. Without TMDB, functions requiring current TMDB data are unavailable. Without Google, alternatives such as ICS export remain available for calendars.

What happens to my existing archive when I move to SerKal Desktop?

SerKal Desktop is being developed so existing SerKal archive data can continue to be used. Before a final migration, the relevant version and installation notes will explain what is carried over and whether any special step is required.
