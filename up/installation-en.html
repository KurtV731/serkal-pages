Install SerKal Desktop

Download, install and start SerKal as a normal Windows application.

Download SerKalPrepare TMDB keyGoogle Calendar help

1. Download

Download SerKal Desktop from the download page.

2. Install

Start serkal-desktop.exe and follow the Windows installation. You can choose the target folder.

3. Start SerKal

SerKal runs as its own Windows application. Normal startup does not require a browser.

4. TMDB

For TMDB search and images, use your own free Developer API key.

5. Google Calendar

Calendar integration is optional and can be set up when you want to use it.

6. Done

Search, manage and archive your series. Later versions update the existing installation.
