Connect Google Calendar with SerKal

SerKal can add your episode dates directly to its own Google Calendar. The setup is intentionally simple for normal users.

What does “Connect Google Calendar” do?

This function connects SerKal to your Google account so that SerKal can create and update calendar entries for your series.

SerKal uses a calendar named SerKal. If that calendar already exists, SerKal uses it. If it does not exist yet, SerKal creates it automatically.

What normally happens

  1. In SerKal, click “Connect Google Calendar”.
  2. Choose the Google account you want to use in the browser.
  3. Allow the access requested for SerKal.
  4. Return to SerKal afterwards.

That is normally all you need to do. SerKal finds the SerKal calendar itself or creates it automatically.

Important for end users: You do not need Google Cloud, a client ID, a JSON file or a calendar ID. These technical details are not part of the user setup.

If the connection does not work

  • First check that you are signed in to the intended Google account in your browser.
  • Start the connection again from SerKal and make sure you allow the requested access.
  • If you cancelled the process or denied access, you can simply start it again from SerKal.
  • If the problem remains, open the normal SerKal help page for current notes and further support.
Not required: Please do not create your own Google Cloud project and do not search for or enter a client ID, JSON file or calendar ID.
