Which calendar option is right?

You opened this page from “Open help” in the second step of SerKal's initial setup. Here is what the four choices mean.

The four choices

Google Calendar – automatically use the “SerKal” calendar
Recommended if SerKal should add episode dates directly to Google Calendar and update them later. SerKal uses an existing calendar named SerKal or creates it automatically. You do not have to enter a calendar ID.

ICS file / another calendar
This option is intended for a future ICS export. The export is not active in the current version, so it does not create calendar entries yet.

Do not use a calendar
SerKal manages your series and local archive without creating calendar entries.

No idea what you want from me – do what you think. 😇
SerKal currently chooses the ICS route, which is not active yet. This option therefore does not create calendar entries at present. Choose the first option if you want dates added directly to Google Calendar.

For Google Calendar: Select the first option and continue with “Next” to the summary. Only “Save all” stores the TMDB and calendar settings together. You can change this choice later at any time via “Calendar”.

What happens during Google sign-in

  1. Create the first actual calendar entry in SerKal.
  2. For this first entry, SerKal opens the Google account selection in your browser.
  3. Allow the access requested for SerKal.
  4. Return to SerKal afterwards.

That is normally all you need to do. SerKal finds the SerKal calendar itself or creates it automatically.

Important for end users: You do not need Google Cloud, a client ID, a JSON file or a calendar ID. These technical details are not part of the user setup.

If the connection does not work

  • First check that you are signed in to the intended Google account in your browser.
  • Start the connection again from SerKal and make sure you allow the requested access.
  • If you cancelled the process or denied access, you can simply start it again from SerKal.
  • If the problem remains, open the normal SerKal help page for current notes and further support.
