Installation

Diese Anleitung ist bewusst einfach gehalten. Bitte die Schritte der Reihe nach durchführen.

1. Google Sheets öffnen

https://sheets.google.com

Auf das große „+“ klicken, um eine neue Tabelle zu erstellen.

Wichtig: Den Code nicht in die Tabelle einfügen. Die Tabelle ist nur der Ausgangspunkt.

2. Apps Script öffnen

Oben auf Erweiterungen klicken und dann Apps Script auswählen.

3. Mehrere Dateien anlegen

SerKal besteht mindestens aus code.gs, ui.html, modul2-suche.gs und modul8-syslog.gs. Die Datei modul9-helfer.gs ist für spätere Fassungen vorbereitet.

4. Code einfügen

Den vollständigen Inhalt in die passende Datei einfügen. Wenn nur die UI eingefügt wird, funktioniert SerKal nicht.

5. Konfiguration

Ordner-ID und TMDB-API-Key korrekt eintragen.

FOLDER_ID
TMDB_API_KEY

6. Speichern

Mit STRG+S oder über das Speichern-Symbol.

7. Zur Tabelle zurück

Apps Script schließen und zur Tabelle zurückkehren.

8. Berechtigungen bestätigen

Beim ersten Start erscheint Googles Sicherheitsmeldung. Diese ist normal.

9. SerKal starten

Im Menü Serienverwaltung auf SerKal öffnen klicken.
