SerKal Desktop installieren

SerKal wird als eigenständiges Windows-Programm installiert. Nach der Installation startest du SerKal ganz normal über die Desktop-Verknüpfung oder das Windows-Startmenü.

1. SerKal herunterladen

Lade den Windows-Installer auf der SerKal-Downloadseite herunter.

2. Installer starten

Öffne die heruntergeladene Datei serkal-desktop.exe und folge der Windows-Installation. Der Zielordner kann bei der Installation gewählt werden.

3. SerKal starten

Nach der Installation steht SerKal als eigenes Windows-Programm bereit. Für den normalen Start ist kein Browser erforderlich.

4. TMDB einrichten

Für Seriensuche, Bilder und TMDB-Wartung benötigt SerKal einen eigenen kostenlosen TMDB Developer-API-Key. SerKal führt bei Bedarf zur passenden Hilfe.

5. Kalender verbinden

Wenn du Folgen in Google Kalender übernehmen möchtest, führt SerKal durch die Kalender-Einrichtung. Die Kalenderfunktion ist optional.

6. Fertig

Danach kannst du Serien suchen, Folgen verwalten und dein lokales Archiv verwenden. Spätere SerKal-Versionen werden als Update über die vorhandene Installation eingespielt.
