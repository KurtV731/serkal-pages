What's new in SerKal 1.2?

Windows and Android move closer together with a shared archive, improved maintenance and more reliable handling of titles and episode dates.

7new feature groups
10general improvements
12specific bug fixes

New features

  • An Android app for your shared archive. Look up series, add seasons, edit notes, change watched status and manage calendar entries from your phone or tablet.
  • One archive across your devices. Use the same Google account on Windows and Android; changes are saved locally first and transferred to Google in the background.
  • Smarter Windows search. Suggestions include title, year and TMDB ID; exact matches and names entered with extra spaces are handled better.
  • Maintenance with a results list. Check missing seasons, new episodes, changed dates and title corrections; reopen the latest result and print it on Windows.
  • Streaming providers by country. See subscription, free, ad-supported, rental and purchase offers reported by JustWatch via TMDB; a manual note can take priority.
  • Announced season starts. Known starts get provisional calendar entries; unknown dates stay unknown.
  • Choose the authoritative archive. If complete archive copies disagree, explicitly decide which one should be adopted by updated devices.

Improvements

  • More consistent German and English titles across search, details, archive and calendar.
  • Maintenance can refresh translated titles without deleting and re-adding a series.
  • Newer seasons can be added without filling the archive with earlier seasons from before you started following a series.
  • A single known episode is no longer treated as a complete schedule; expected episode counts do not invent dates.
  • Confirmed schedules replace provisional entries; less complete later data does not shorten them.
  • Clearer distinction between a local save, pending transfer and Google-confirmed save.
  • Shared-archive version checks and improved recovery after interrupted transfers.
  • Easier reuse of a TMDB API key on devices using the same Google account.
  • More consistent light/dark presentation, menus and archive status indicators.
  • Compact Android footer with flags, light/dark selection, calendar, help and a real Exit action.

Bug fixes

  • Regional aliases no longer take priority over the appropriate English title.
  • Calendar entries use the stored translated title instead of a German archive filename.
  • Duplicate archive files for the same TMDB series after title changes are prevented.
  • Watched status can be set and switched back again.
  • Edits are no longer undone by repeatedly applying an accepted authoritative archive.
  • The misleading “archive is being prepared” message that could hide a conflict and block deletion was fixed.
  • Calendar-target detection and errors for missing or inaccessible calendars were improved.
  • Recovery was improved when an upload succeeds but its confirmation is interrupted.
  • Android lists again use the available screen height.
  • Android search resets cleanly after an archive entry; delayed responses cannot refill cleared fields.
  • Android Exit closes the app task instead of only moving it to the background.
  • Windows closing and update handling were improved, including open save dialogs and pending changes.

Important when updating

  • Update all devices that use the shared archive before resuming normal use.
  • After an edit, wait for the Google-confirmed save or use Sync now when needed.
  • For older incorrectly translated titles, choose the required language and run Maintenance; protected values remain protected.
  • Episode dates and provider information are refreshed through maintenance and are not a continuous live feed.
  • Android is supplied as an APK; Google Play Store availability is not announced.
